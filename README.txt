1. Create a NEW GitHub repo (e.g. nc-checker-android), upload ALL files from this folder (incl. hidden .github folder).
2. Actions tab -> "Build Android APK" -> wait ~5 min -> Artifacts -> NC-Checker-apk -> download, unzip -> app-debug.apk
3. Send apk to the phone, open it, allow "install unknown apps".
Updates: the app checks the same GitHub 'publish' folder as the PC app on every start; new page applies on the next launch.
